# 麦麦省钱作战室 (McSaver War Room)

> 基于**麦当劳中国 MCP** 的多目标最优解点餐引擎 —— 一句话说出预算和营养目标，自动领券、比价、算最优组合。

「麦麦省钱作战室」是一个面向麦当劳点餐决策的 AI Skill。它把**真实优惠券 + 真实门店菜单 + 真实营养数据**
喂给一个组合优化引擎，在预算与营养约束下求解**帕累托最优**的点餐方案，并用麦当劳官方的
`calculate-price` 工具对方案做价格校验，最终给出可执行的「领券 + 下单」路径。

本项目为「麦当劳程序员创意开发大赛」参赛作品，由参赛者独立开发，非麦当劳官方产品。

## ✨ 核心能力

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| 💰 最省钱 | 预算内实付最低 | 日常省钱 |
| 📈 性价比最高 | 每元营养最高 | 想吃得值 |
| 💪 高蛋白限热量 | 限热量内蛋白最大化 | 减脂 / 增肌 |
| 🍟 件数最多 | 预算内件数最大化 | 解馋 / 拼单 |
| ⚖️ 均衡 | 价格×营养帕累托前沿 | 不知道吃什么 |

与「只列券」类方案的本质区别：**真的在做组合优化**（枚举候选篮 → 应用最优券叠加 → 约束过滤 → 帕累托排序），
且以官方 `calculate-price` 为最终价格权威。

## 📦 安装方法

### 1. 申请麦当劳 MCP Token
前往 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，手机号登录后于「控制台 → 激活」申请 Token。

### 2. 在 WorkBuddy 接入 mcd-mcp
左侧边栏【专家·技能·连接器】→【连接器】→【自定义连接器】→【配置 MCP】，填入
`mcp-config.example.json` 内容并将 `${MCD_MCP_TOKEN}` 替换为你的真实 Token，保存并启用。

> 本地调试时，可将 Token 写入环境变量：`export MCD_MCP_TOKEN=你的真实Token`（配置文件本身始终保持占位符）。

### 3. 加载本 Skill
将本仓库 `skill/` 目录作为 WorkBuddy Skill 加载（或直接放置于 WorkBuddy 的 skills 目录）。

### 4. 运行优化引擎（可选，离线验证）
引擎为纯标准库 Python，无需安装依赖：

```bash
python scripts/saver_engine.py --demo --goal high_protein --budget 40 --max-cal 700
```

## 🧪 使用示例

在 WorkBuddy 对话框中直接表达目标即可触发：

- 「预算 30 怎么点最划算」→ 最省钱方案
- 「40 块吃到蛋白质最高，热量别超 700」→ 高蛋白限热量方案
- 「20 块解个馋，件数越多越好」→ 件数最多方案
- 「预算 50，给我几个均衡方案」→ 帕累托均衡方案

引擎会输出方案卡（商品清单 / 原价 / 优惠 / 实付 / 热量 / 蛋白 / 用券明细），并用
`calculate-price` 二次校验实付，最后给出领券与下单路径。

### 离线演示输出示例

## ✅ 真实端到端联调验证（2026-10-18）

本作品已在 WorkBuddy 中通过 `mcd-mcp` 连接器**真实调用**麦当劳 MCP 完成端到端验证（到店自取场景）：

1. `query-nearby-stores(北京, 国展)` → 麦当劳北京后沙峪餐厅（storeCode `1950142`）
2. `query-meals` → 拉取该店真实在售菜单（上百餐品 + 现价/原价/优惠类型）
3. `list-nutrition-foods` → 官方营养库
4. `scripts/real_demo.py` 将「菜单(按 code) + 营养(按 name)」对齐后做组合优化
5. `calculate-price` 二次校验，结果与优化器估算 **100% 一致**：

| 方案 | 估算 | 官方 | 一致 |
| --- | --- | --- | --- |
| 麦乐鸡×1 + 双层吉士汉堡×1 | ¥37.50 | ¥37.50 | ✅ |
| 那么大鸡排(椒盐)×1 | ¥14.50 | ¥14.50 | ✅ |
| 脆薯饼×2 + 圆筒×2 + 苹果片×2 | ¥40.00 | ¥40.00 | ✅ |
